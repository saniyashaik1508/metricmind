# 🚀 MetricMind – AI-Powered Semantic Business Intelligence Engine

MetricMind is a modern Business Intelligence platform that combines AI, semantic modeling, and interactive dashboards to help organizations analyze revenue, cost, profit, and business performance using natural language.

---


# ✨ Features

- 📈 Interactive BI Dashboard
- 🤖 AI Business Assistant
- 📊 Revenue, Cost & Margin Analytics
- 🌍 Region-wise Performance Analysis
- 📅 Quarterly Business Reports
- 🏆 Top Products Analysis
- 📉 Revenue Trend Charts
- 🧠 Semantic Layer for Business Metrics
- ⚡ Express.js API
- 🚀 Next.js 14 Frontend
- 🎨 TailwindCSS UI
- 📂 dbt Data Models

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/saniyashaik1508/metricmind.git
```

Go inside the project

```bash
cd metricmind
```

Install packages

```bash
npm install
```

Run the project

```bash
npm run dev
```

Open

```
http://localhost:3000
```
